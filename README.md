# ☀️ 공공 GIS 도로망 및 실시간 기상 데이터 기반 폭염 안전 보행 경로 탐색

> **2026 KISM 춘계학술대회 발표 연구**  
> 폭염 시 보행자의 온열 질환 위험을 줄이기 위해 공공 GIS 보행자 도로망 데이터와 실시간 기상 관측 데이터를 결합하여, 최단 거리가 아닌 **열환경 안전도가 반영된 최적 보행 경로**를 탐색하는 라우팅 알고리즘 프로젝트입니다.

---

## 📌 프로젝트 배경 및 목적
- 기존 보행자 내비게이션은 최단 거리·최소 시간 위주로 경로를 안내하여, 폭염 특보 시 그늘이 없거나 복사열이 높은 구간으로 보행자를 유도하는 한계가 있습니다.
- 본 프로젝트는 **공공 GIS 도로 네트워크**에 **실시간 기상 데이터(기온, 습도, 체감온도 등)**를 공간 매핑하여 도로 구간별 열스트레스 가중치를 산출하고, 안전한 보행 경로를 도출합니다.

## ⚙️ 핵심 구현 내용
1. **GIS 보행자 도로 네트워크 구축**
   - 공공 공간정보 데이터를 기반으로 노드(교차로)와 엣지(보행로) 그래프 구조 생성
2. **실시간 기상 데이터 수집 및 공간 보간**
   - 기상 관측 API를 통해 실시간 기상 변수 수집 및 각 도로 세그먼트에 기상 가중치 매핑
3. **폭염 안전 경로 탐색 알고리즘**
   - 거리 비용과 열위험도 비용을 결합한 복합 가중치 함수를 적용해 기존 최단 경로 대비 열 노출을 최소화한 경로 산출

## 🛠 기술 스택
- **Language:** Python 3
- **Data & Spatial Analysis:** Pandas, NumPy, GIS / Graph Routing
- **External Data:** 공공 GIS 도로망 데이터, 실시간 기상 관측 API

## 🚀 실행 방법
1. 저장소 우측 상단 `Code` → `Download ZIP` 또는 로컬 환경에 내려받기
2. 프로젝트 루트 경로에 `.env` 파일을 생성하고 기상청 API 인증키 입력
3. 필요한 파이썬 패키지 설치 후 메인 스크립트(`main.py`) 실행
